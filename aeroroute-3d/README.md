# AeroRoute 3D

## One-line definition

3D route-readiness sandbox for dense-city drone delivery — evaluate whether a candidate drone corridor is operationally feasible before launch.

## Project purpose

Content foundation for a portfolio case study aimed at route launch and operations strategy teams. Supports pre-operation route assessment (not real-time flight control).

## Folder structure

| Path | Purpose |
|------|---------|
| `prd.md` | Product requirements and scope |
| `website-copy.md` | Slide-like section copy (EN) |
| `slide-content.ts` | Structured slide data for future UI |
| `project-meta.ts` | Portfolio listing metadata |
| `constraints.md` | Writing and product guardrails |
| `research-notes.md` | Research and reference notes |
| `data/` | Candidate nodes and data boundaries |
| `assets/` | Screenshots and visual placeholders |
| `prompts/` | Codex prompts for slides and style |

**Content scaffold only** — no webpage, routes, or global style changes yet.
